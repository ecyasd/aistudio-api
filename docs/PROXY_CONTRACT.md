# 反代的边界与验收

本服务把 Gemini HTTP/JSON 接口转换为 AI Studio 的浏览器请求及 JSPB 响应。
核心职责是保持协议语义、隔离账号和可靠结束请求。协议转换集中在网关编解码层；
API 层处理认证和公共响应，应用层处理准入、调度及显式启用的续写。

生成请求由 GenerationRun 内部的固定恢复实现决定是否再次尝试，HTTP 不提供恢复策略。
准入与恢复终态通过框架无关的应用异常传出，JSON/SSE 共用错误投影；API 入口继续保持
既有 HTTP 异常契约。已归一终态不再进入账号恢复或重复失败记账。
浏览器原流重送、模型请求再次尝试与 MAX_TOKENS 续写分别保持原有预算和归属。

```mermaid
flowchart LR
    C[Gemini 客户端] --> H[HTTPS 网关]
    H --> A[调用认证与有界准入]
    A --> L[账号上下文租约]
    L --> W[Gemini / JSPB 编解码]
    W --> B[私有 CDP 与浏览器传输]
    B --> U[AI Studio]
    U --> B --> W --> A --> C
```

## 协议保真

- 文本、思考、图片、函数调用、可执行代码和执行结果按 Part 顺序输出；保留其签名和思考归属。
- 客户端清理后只剩空 Part 的历史轮次可跳过；末轮为空时在本地返回 400。
  独立签名 Part、显式空文本及工具/多模态 Part 保留，不按空历史丢弃。
- 只有真实完成原因、完整 JSON 包络和成功传输共同成立，才算生成完成。
  无正文的合法完成/阻止帧可以接受，非空但畸形的 content/Part 必须明确失败。
- HTTP 200 后发生的流式失败以 SSE 错误报告，不能用已发送的文本伪造正常结束。
- 普通模型不追加续写。`抗截断/<base>` 是显式模式，只在真实 MAX_TOKENS 后执行有界续写；
  工具、代码执行等不安全的历史不自动续写，保留上游完成原因。
- 配置支持的参数默认值和参数过滤属于明确的兼容策略；不能把猜测的正文修改混入解析器。

## 身份与资源归属

管理 Bearer、API 调用密钥、Google 会话分别承担独立职责。未配置管理密码时，
管理接口拒绝访问；空 API 密钥集合拒绝模型调用。公开健康检查不启动浏览器或访问 Google。

每个生成请求租用确定账号的上下文。重新导入会话后，新请求使用新的凭据代际；
旧请求可以排干，其晚到错误不能把新代际标为过期。删除最后账号进入无账号状态，
不能转而尝试匿名登录。账号路径解析后必须严格位于账号根目录之下。

推理并发、等待队列、响应字节和传输缓冲都有上限。流式传输的首次响应期限包含
Cookie 刷新、CDP binding 注册和浏览器请求初始化；之后按既定空闲期限检测失联。
消费者暂停时通过确认机制向浏览器反压；等待确认期间暂停上游空闲计时，改由独立的
慢消费者期限约束。超时、取消、断连或越界均释放任务、队列和租约。
流式 binding 注册失败在派发前报告；响应头等待超时保留 504 语义。无片段时以有界、
脱敏的浏览器状态检查区分上游等待与推送失联。已有待确认片段可经独立通道重送一次，
按请求及序号去重，保留原流和其他活动请求；无法恢复的通道以 503 结束，正文发出后不重发模型请求。
派发前若明确回执推送函数缺失且尚未调用 fetch，先安装独立通道再初始化一次；不拆除其他流的通道。
完成通知也有序号并等待确认，丢失时可恢复同一个原流，收到确认后才清理浏览器状态。
注册备用通道期间迟到的原片段正常交付；尚未实际重送时，不消耗后续丢失片段的重送机会。
传输恢复失败、首包或上游无进展超时均直接结束，不落入通用会话挂起的切号重试；429、认证和完整性恢复保持各自的有界策略。
恢复时的原生 CDP 异常也归为终态通道失败；非流式浏览器返回的 timeout 保持 504，
派发后的状态／完成确认失败、页面关闭和浏览器通道中止同样终止原请求，不切号重放。
传输失败与超时均不因期间更换凭据代际而重放。内部生成故障只返回固定 500 消息，服务日志
记录固定分类、异常类型和安全堆栈位置，不保存认证异常原文。
非流式请求一旦进入浏览器执行，原生 CDP 异常、浏览器中止或正文读取失败同样归为终态
传输失败，以 503 结束，不切号或重复生成；执行前的准备恢复策略保留，超时仍为 504。
响应活动期间的客户端断连不能因 HTTP 中间件补发空结束帧而改记为成功。
生成完成后的可选 Cookie checkpoint 使用 3 秒预算，超时保留上次有效导出并继续完成响应；
自动续写只给该 checkpoint 剩余的请求预算，保存超时不把已经完成的生成改记为 504。
取消在原任务及原租约内清理，不留下跨请求后台写入。

## 配置与交付

管理页面保存 YAML 时发送加载基线；服务端在同一写锁内仅合并显式修改的顶层字段。
未修改的日志及未来扩展字段保留最新值；同字段已被另一操作修改时返回 409 并保留编辑草稿。
调用密钥始终由专用路径维护。没有基线的旧 YAML 客户端仍表示显式替换整个非密钥文档，
并发编辑客户端应发送 `baseline_yaml_content`。

管理接口 `POST /config/model-preview` 接受模型名及可选 `yaml_content` 草稿，复用运行时规则编译和合并逻辑，返回命中顺序与规范化默认配置。
不写文件、不改运行时缓存、不准备账号或调用模型；省略草稿时读取已保存规则。预览只解释默认规则，不模拟客户端显式参数或上游模板。
配置读取与缺失文件初始化分开；运行时按文件版本缓存同一文档编译出的规则组和精确覆盖，
直接修改文件后整份规则快照更新，避免预览与实际生成使用不同版本。
预览入口跳过请求转储配置读取，避免日志中间件间接初始化文件或更新缓存；草稿不进入请求转储。
未知生成属性单独列出，不伪装成有效参数。调用密钥和其他顶层配置不会返回。
预览与编码器共用支持字段集合；未知属性保留在配置中，但不会修改编码器的内部存储或方法。

`GET /api/accounts/active` 在没有活跃账号时返回 `200 null`，属于正常空状态，不污染最近错误窗口。
`GET /errors` 的 `account_id`、`request_id` 对错误记录先筛选再分页，也限定响应探测范围；错误码及分类不筛掉成功响应探测。
响应探测的 `account_ids` 只来自实际租约及安全失败归属，包含一次请求跨账号重试的成员，不根据当前 UI 选中账号推断。
从账号进入诊断后可跳到完整请求链路；请求链路链接清除账号限制以展示跨账号尝试。过期或已删除账号的记录仍按原身份保留至窗口到期。

运行配置和账号数据位于代码版本之外。容器挂载配置父目录以支持原子替换；已有部署
先用保留原文件且拒绝覆盖的迁移工具准备目录。代码发布及回滚只切换经过 CI 的代码，
不替换运行配置、账号、浏览器数据、统计或生产依赖。
平滑关闭时先完成客户端清理，再取消并等待统计保存计时任务，写入最终模型和账号快照，
随后才释放应用运行引用。

## 离线验收入口

| 不变量 | 主要回归 |
| --- | --- |
| 生成模块的同任务租约、尝试元数据隔离与发布后禁止重放 | `tests/unit/test_generation_run.py`、`tests/unit/test_gemini_sse_lifecycle.py` |
| 坏内容不能伪装完成；代码与思考图片保真 | `tests/unit/test_proxy_part_fidelity.py`、既有协议/SDK 回归 |
| 凭据重导入、旧租约和无账号状态 | `tests/unit/test_account_generation_boundaries.py` |
| 传输准备阶段超时及资源回收 | `tests/unit/test_transport_setup_deadline.py`、`test_stream_transport.py` |
| 并发设置保存及草稿保留 | `tests/unit/test_config_snapshot_merge.py`、`tests/frontend/settings_state.mjs` |
| 规则预览、账号/请求关联及空账号状态 | `tests/unit/test_management_insights.py`、`tests/unit/test_routes_accounts.py`、`tests/frontend/error_records.mjs` |
| 管理认证、容器持久化与发布边界 | 认证、Compose、构建及部署工具的离线回归 |

通过离线回归表示转换、隔离和清理在合成场景下满足约束。真实上游的页面或私有协议
变化仍需根据被动、脱敏证据判断；部署验收不调用模型、不探活或激活账号。
