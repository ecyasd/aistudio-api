# 反代的边界与验收

本服务把 Gemini HTTP/JSON 接口转换为 AI Studio 的浏览器请求及 JSPB 响应。
核心职责是保持协议语义、隔离账号和可靠结束请求。协议转换集中在网关编解码层；
API 层处理认证和公共响应，应用层处理准入、调度及显式启用的续写。

```mermaid
flowchart LR
    C[Gemini 客户端] --> H[HTTPS 网关]
    H --> A[调用认证与有界准入]
    A --> L[账号上下文租约]
    L --> W[Gemini / JSPB 编解码]
    W --> B[私有 CDP 与浏览器传输]
    B --> U[AI Studio]
    U --> B --> W --> A --> C
```

## 协议保真

- 文本、思考、图片、函数调用、可执行代码和执行结果按 Part 顺序输出；保留其签名和思考归属。
- 只有真实完成原因、完整 JSON 包络和成功传输共同成立，才算生成完成。
  无正文的合法完成/阻止帧可以接受，非空但畸形的 content/Part 必须明确失败。
- HTTP 200 后发生的流式失败以 SSE 错误报告，不能用已发送的文本伪造正常结束。
- 普通模型不追加续写。`抗截断/<base>` 是显式模式，只在真实 MAX_TOKENS 后执行有界续写；
  工具、代码执行等不安全的历史不自动续写，保留上游完成原因。
- 配置支持的参数默认值和参数过滤属于明确的兼容策略；不能把猜测的正文修改混入解析器。

## 身份与资源归属

管理 Bearer、API 调用密钥、Google 会话分别承担独立职责。未配置管理密码时，
管理接口拒绝访问；空 API 密钥集合拒绝模型调用。公开健康检查不启动浏览器或访问 Google。

每个生成请求租用确定账号的上下文。重新导入会话后，新请求使用新的凭据代际；
旧请求可以排干，其晚到错误不能把新代际标为过期。删除最后账号进入无账号状态，
不能转而尝试匿名登录。账号路径解析后必须严格位于账号根目录之下。

推理并发、等待队列、响应字节和传输缓冲都有上限。流式传输的首次响应期限包含
Cookie 刷新、CDP binding 注册和浏览器请求初始化；之后按既定空闲期限检测失联。
消费者暂停时通过确认机制向浏览器反压，超时、取消、断连或越界均释放任务、队列和租约。

## 配置与交付

管理页面保存 YAML 时发送加载基线；服务端在同一写锁内仅合并显式修改的顶层字段。
未修改的日志及未来扩展字段保留最新值；同字段已被另一操作修改时返回 409 并保留编辑草稿。
调用密钥始终由专用路径维护。没有基线的旧 YAML 客户端仍表示显式替换整个非密钥文档，
并发编辑客户端应发送 `baseline_yaml_content`。

运行配置和账号数据位于代码版本之外。容器挂载配置父目录以支持原子替换；已有部署
先用保留原文件且拒绝覆盖的迁移工具准备目录。代码发布及回滚只切换经过 CI 的代码，
不替换运行配置、账号、浏览器数据、统计或生产依赖。

## 离线验收入口

| 不变量 | 主要回归 |
| --- | --- |
| 坏内容不能伪装完成；代码与思考图片保真 | `tests/unit/test_proxy_part_fidelity.py`、既有协议/SDK 回归 |
| 凭据重导入、旧租约和无账号状态 | `tests/unit/test_account_generation_boundaries.py` |
| 传输准备阶段超时及资源回收 | `tests/unit/test_transport_setup_deadline.py`、`test_stream_transport.py` |
| 并发设置保存及草稿保留 | `tests/unit/test_config_snapshot_merge.py`、`tests/frontend/settings_state.mjs` |
| 管理认证、容器持久化与发布边界 | 认证、Compose、构建及部署工具的离线回归 |

通过离线回归表示转换、隔离和清理在合成场景下满足约束。真实上游的页面或私有协议
变化仍需根据被动、脱敏证据判断；部署验收不调用模型、不探活或激活账号。
